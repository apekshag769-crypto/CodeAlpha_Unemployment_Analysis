# 📊 CodeAlpha Task 2 — Unemployment Analysis with Python

## 📌 Project Overview

This project was completed as part of the **CodeAlpha Data Science Internship**.

The objective of this project is to analyze unemployment trends in India using Python and identify important patterns in unemployment, employment, labour participation, regional differences, and the impact of the COVID-19 period.

## 🎯 Objectives

- Analyze unemployment trends over time
- Identify regional differences in unemployment
- Compare unemployment between urban and rural areas
- Analyze the impact of COVID-19 on unemployment
- Study employment and labour participation trends
- Identify important patterns and insights
- Visualize the results using Python

## 📂 Dataset

The project uses the **Unemployment in India** dataset.

The dataset contains information related to:

- Region
- Date
- Frequency
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate
- Area

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## 🔍 Analysis Performed

### 1. Data Cleaning
- Removed unnecessary spaces
- Converted date values
- Converted numerical columns
- Handled missing values

### 2. Exploratory Data Analysis
- Dataset overview
- Statistical summary
- Region-wise analysis
- Urban vs Rural comparison

### 3. Unemployment Trend Analysis
Analyzed changes in unemployment rates over time.

### 4. COVID-19 Impact Analysis
Compared unemployment levels before and during the COVID-19 period.

### 5. Employment Analysis
Studied changes in estimated employment over time.

### 6. Labour Participation Analysis
Analyzed labour participation trends.

### 7. Correlation Analysis
Examined relationships between unemployment, employment, and labour participation.

## 📈 Key Insights

- Unemployment rates varied considerably across different regions.
- Urban and rural areas showed differences in unemployment levels.
- A significant change in unemployment was observed during the COVID-19 period.
- Employment and labour participation also changed during the study period.
- Data visualization helped identify important unemployment trends and patterns.

## 📊 Visualizations

The notebook includes visualizations for:

- Overall unemployment trend
- Region-wise unemployment
- Urban vs Rural unemployment
- COVID-19 impact
- Monthly unemployment trend
- Employment trend
- Labour participation trend
- Correlation heatmap
- Top regions with higher unemployment

## ✅ Conclusion

This project demonstrates how Python-based data analysis and visualization can be used to study real-world economic data.

The analysis provides insights into unemployment trends in India and highlights the impact of the COVID-19 period on the labour market.
